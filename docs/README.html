阅读约定 ​

  • 学习目标与前置知识：每章开头引用块给出，可跳读；第 6/7 章依赖第 2~5 章的基础。
  • 代码示例：每个可独立运行的示例块后附「运行方式」行；跨文件的完整示例统一放在 examples/ 目录。
  • 漫画映射：每章末「🎬 配套漫画」小节包含漫画格 ↔ 小节映射表，标注每个知识点在漫画中的第几格。
  • 反向链接：漫画讲解稿（comics/EP.0N.md）的每个「节点」都带有 📖 链接跳回本章对应小节，两向均可导航。

建议学习顺序 ​

  1. 入门：EP.01~09 漫画过一遍（约 30 分钟）建立全局认知 → 再按章精读。
  2. 系统学习：按 01 → 09 顺序精读，每章末尾跳转对应漫画巩固。
  3. 按需查阅：目录表直接定位问题域（如「滚动卡顿」→ 第 4 章；「内存涨」→ 第 5 章）。
