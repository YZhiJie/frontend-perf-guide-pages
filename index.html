前端性能优化完全学习指南

一套双形态深度联动的前端性能优化学习资料体系：标准技术文档 + 漫画剧场。同一套知识，两种呈现——文档严谨完整可作参考手册，漫画场景化降低理解门槛，双向锚点随时切换。

frontend-perf-guide/
├── docs/        # 标准技术文档教程（9 章，系统性 + 按需查阅）
├── comics/      # 漫画式教程（9 话四格漫画 + 讲解稿 + 阅读器）
├── examples/    # 可直接运行的示例集（5 个，Node/浏览器）
└── scripts/     # 双向映射校验门禁（check-mapping.mjs）

部署方式

站点是纯静态产物，无需服务端；构建与发布流程：

npm install            # 首次：安装构建依赖（marked，仅构建期使用）
npm run build:pages    # 将 markdown 教程渲染为 dist-pages/ 静态站点
# 再把 dist-pages/ 推送到部署仓库 frontend-perf-guide-pages 的 main 分支

部署仓库已开启 GitHub Pages（Source: main 分支根目录），站点即发布到上述线上地址。源码仓库保持私有，仅部署仓库公开可访问。

两种内容形态

标准技术文档（docs/） 漫画式教程（comics/）
定位 系统性学习 + 日常技术参考手册 快速建立整体认知 + 破除认知误区
内容 指标详解、底层原理、可运行代码、工具指南、生产落地流程 生活化场景故事、四格图解、误区对比表
适合 想搞懂「为什么」和「怎么做」 想先知道「是什么、为什么重要」

双向关联映射：文档每章末尾有「🎬 配套漫画」小节（含漫画格 ↔ 小节映射表）；每话漫画讲解稿的每个知识点节点带 📖 链接跳回文档对应小节。该映射由 scripts/check-mapping.mjs 门禁自动强制校验，永不失联。

学习路径（三种入口）

  • 漫画入门（约 30 分钟）：打开 comics/index.html 阅读器，把 9 话漫画刷一遍 → 再进入文档精读感兴趣的小节。
  • 系统学习：从 docs/01-overview.md 开始按章精读，每章末尾跳漫画巩固 → 适合完整掌握全链路。
  • 按需查阅：遇到具体问题直接查对应章节（加载慢 → 第 3 章、滚动卡 → 第 4 章、内存涨 → 第 5 章、框架专项 → 第 6/7 章）。

框架适配说明

第 6/7 章分别针对 Vue 3（Proxy 响应式开销、v-memo/shallowRef/markRaw、KeepAlive、unplugin 按需引入、Pinia 选择器订阅）与 React 18/19（memo 三件套、状态下放与 children 穿透、useTransition/useDeferredValue、外部状态库 selector 订阅、React 19 Compiler 自动记忆化）提供专项方案；其余各章的通用方案在两章中均有框架化落地代码，可直接用于生产。

质量门禁

node scripts/check-mapping.mjs            # 全量校验：SVG 规范 + 双向映射 + 死链 + manifest 一致性
node scripts/check-mapping.mjs --svg-only # 仅校验 SVG 硬规则（供新增漫画时快速自检）

校验范围：SVG 硬规则（viewBox、无外部资源、字号显式、行宽、引用完整性）、文档章末漫画映射、漫画节点回链、全仓库 Markdown 死链（含 GitHub 锚点 slug 规则）、manifest 与磁盘一致性。
