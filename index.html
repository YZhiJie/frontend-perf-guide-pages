学习路径（三种入口） ​

  • 漫画入门（约 30 分钟）：打开 comics/index.html 阅读器，按分册把 9 话漫画刷一遍 → 再进入文档精读感兴趣的小节。

    阅读器读取 manifest.json 与讲解稿，需通过 HTTP 访问（本地 python3 -m http.server，或直接用上面的线上地址）。

  • 系统学习：从 docs/01-overview 开始按章精读，每章末尾跳漫画巩固 → 适合完整掌握全链路。
  • 按需查阅：遇到具体问题直接查对应章节（加载慢 → 第 3 章、滚动卡 → 第 4 章、内存涨 → 第 5 章、框架专项 → 第 6/7 章）。

快速开始 ​

bash
npm install            # 安装 vitepress
npm run docs:dev       # 本地开发：http://localhost:5173
npm run docs:build     # 构建静态站点
npm run docs:preview   # 预览构建产物

质量门禁 ​

bash
node scripts/check-mapping.mjs            # 全量校验：SVG 规范 + 双向映射 + 死链 + manifest 一致性
node scripts/check-mapping.mjs --svg-only # 仅校验 SVG 硬规则
node comics/check-comics.mjs              # manifest + SVG 良构 + 讲解稿完整性
node comics/check-renderer.mjs            # 内置渲染器对 9 话讲解稿的自测
