阅读器

index.html 是零依赖单文件阅读器，内容序列来自 manifest.json。

能力 说明
封面 系列徽章、书名、话数与分册数、继续阅读（进度记忆）
双模式 paged 一屏一话翻页 / scroll 长卷连续滚动
讲解抽屉 右侧滑出当前话讲解稿，内置 Markdown 渲染器；可打开原始 Markdown
话目总览 按分册（九章）分组的网格，支持关键词搜索与进度标记
深链 #ep-07 直达第 7 话；#ep-07/p3 直达第 3 格
键盘 ←/→ 上下话、↑/↓ 翻页、N 讲解抽屉、G 话目总览、Esc 关闭

⚠️ 阅读器在运行时 fetch 读取 manifest.json 与讲解稿，必须通过 HTTP 访问： 本地运行 python3 -m http.server 8899 后打开 http://127.0.0.1:8899/comics/index.html； 直接双击 file:// 打开会被浏览器安全策略拦截（可改用上表直接看 SVG 与 MD）。

与标准文档的联动规则

  • 每话讲解稿（EP.N.md）的知识点节点都带 📖 链接，精准跳转到标准文档对应小节；
  • 讲解稿末的「自测三题」用于快速检验理解，答案折叠在引用块中；
  • 标准文档每章末尾的「🎬 配套漫画」小节给出漫画格 ↔ 文档小节的双向映射表；
  • 双向链接由门禁脚本自动校验。

校验

node comics/check-comics.mjs     # manifest 一致性 + SVG 良构 / 文本溢出 + MD 完整性
node comics/check-renderer.mjs   # 内置渲染器对全部讲解稿的渲染自测
node scripts/check-mapping.mjs   # 文档 ↔ 漫画双向映射与锚点死链
