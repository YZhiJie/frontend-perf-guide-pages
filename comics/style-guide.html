漫画剧场风格规范 · 性能小镇 Perf Town v2.0

本规范是 comics/ 全部漫画的唯一视觉与叙事标准。新增或修改任何一话，都必须对照本文档执行。 校验入口：node comics/check-comics.mjs（manifest 一致性 + SVG 良构性 + 文本溢出启发式 + MD 完整性）。

2. 色板

用途 色值

对比度规则：浅底配深字（#0f172a）；深底（#334155）配白字；所有正文对比度 ≥ 4.5:1。

3. 字号阶梯与文本

元素 字号 字色
话标题（页眉） 25 bold #ffffff
面板标题 16 bold #0f172a
气泡/正文 14~16 #0f172a / #334155
代码 12~13 mono #0f766e / #b45309
注脚/映射行 12 #94a3b8
  • font-family="'PingFang SC','Hiragino Sans GB','Microsoft YaHei',sans-serif"；代码用 'SF Mono','JetBrains Mono',Consolas,monospace。
  • 每个 <text>/<tspan> 必须显式写 font-size（校验脚本依赖）。
  • 单行估宽 ≤ 545px（CJK 字符按字号全宽计，ASCII 按 0.58×字号）；超宽请拆成多行 <tspan>。
  • 文本中 < → &lt;、> → &gt;、& → &amp;；禁止外部 http 资源。

4. 组件规范

  • 面板标题：位于每格左上，x=18 y=24，16px 粗体深色，格式「第 N 格 · 四到八字标题」。
  • 模块标题条：需要分区时用深色圆角条 + 白字，宽度随文本自适应。
  • 对话气泡：白色圆角矩形 + 指向角色的小三角；气泡内文字 ≤ 2 行。
  • 代码芯片：浅灰/深底圆角矩形 + 等宽字体，单行 ≤ 40 字符。
  • 坑点徽章：橙色圆角条 + 「坑点」白字，只出现在第 4 格。
  • 稳叔总结框：白底绿框（#059669），左上角绿色粗体「稳叔总结」。
  • 映射行：第 4 格底部 12px 灰色，格式 📄 对应文档：docs/0N-xxx.md#小节。

6. 叙事结构（四幕）

  1. 第一格 · 困境：真实业务场景抛出性能问题（页面卡了 / 指标红了 / 被用户投诉）；
  2. 第二格 · 揭秘：原理拆解，配 1 段迷你代码或流水线示意；
  3. 第三格 · 实证：正确 vs 错误的对比、执行顺序或成本阶梯；
  4. 第四格 · 结案：常见误区 → 正解 + 稳叔一句话总结 + 文档映射行。

7. 命名与文件

  • 一话 = EP.NN.svg + EP.NN.md，NN 两位数（本项目保持短名，便于 docs 九章双向链接）；
  • 一话严格对应正文一个章节：ep.part 指向 docs/ 下的 NN-xxx.md；
  • 新增话必须同步：manifest.json（episodes + 必要时 parts）、comics/README.md 导航表；
  • 讲解 MD 结构固定： # EP.NN · 《标题》 → > 漫画/对应文档 导语 → ## 本话剧情 → ## 知识点节点（≥3 个 ### 节点 N ·，每节点含生活映射/技术对应/深入阅读回链）→ ## 常见认知误区（表格）→ ## 自测三题（含答案）→ ## 一句话带走 → 上下话导航。

8. 阅读器交互约定

comics/index.html 为整合阅读器（零依赖单文件）：

  • 封面：系列徽章、书名、话数与分册数、开始阅读 / 话目总览入口；
  • 双模式：paged 翻页（一屏一话，滚轮/滑动切话）与 scroll 长卷（连续滚动，滚动位置记进度）；
  • 讲解抽屉：右侧滑出当前话的 MD 讲解（由前端内置渲染器渲染），支持「打开原始 Markdown」；
  • 话目总览：按分册分组的全部话目网格，支持关键词搜索、进度标记、一键直达；
  • 进度记忆：localStorage 记录每话阅读比例，封面显示继续阅读；
  • 深链：#ep-07 直达第 7 话；#ep-07/p3 直达第 3 格；
  • 键盘：←/→ 上下话，↑/↓ 翻页，N 开合讲解抽屉，G 话目总览，Esc 关闭。

阅读器运行时 fetch 读取 manifest.json 与讲解 MD，因此需通过 HTTP 访问（本地 python3 -m http.server 或线上 Pages），直接双击 file:// 打开会被浏览器安全策略拦截。

9. 校验入口

node comics/check-comics.mjs     # manifest / SVG 良构 / 文本溢出 / MD 完整性
node comics/check-renderer.mjs   # 内置渲染器对全部讲解稿的渲染自测
node scripts/check-mapping.mjs   # 文档 ↔ 漫画双向映射与锚点死链
